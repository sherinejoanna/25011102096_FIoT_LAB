# STM32 Microcontroller Experiments (CAT 8 – CAT 13)

These STM32 projects use CubeMX for configuration and HAL for peripheral access. Each task includes the CubeMX files (`*.ioc`, `.mxproject`), the application and driver directories (`Core/`, `Drivers/`), Keil MDK-ARM files under `MDK-ARM/`, STM32CubeIDE metadata (`.project`, `.cproject`), a circuit image, and an experiment write-up in `README.md`.
